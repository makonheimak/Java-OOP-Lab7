### Описание заданий

#### Задание 1 (Базовое): Встроенный многопоточный HTTP-сервер
- **Класс:** `HttpServerApp.java`
- **Суть:** Реализация локального веб-сервера на базе `com.sun.net.httpserver.HttpServer`:
  - Настройка порта (по умолчанию `8080`) и пула потоков `ThreadPoolExecutor`.
  - Обработка HTTP-методов `GET` и `POST`.
  - Формирование заголовков ответов (`Content-Type`, `charset=utf-8`, коды состояния 200, 404, 405).
  - Отдача HTML-страниц и структурированных данных JSON.

#### Задание 2 (Продвинутое): Архитектура контроллеров и маршрутизация
- **Классы:** `Route.java`, `WebController.java`, `SpringMvcSampleController.java`
- **Суть:**
  - `Route.java` и `WebController.java`: реализация шаблона диспетчера запросов с сопоставлением URL-путей и обработчиков (эндпоинты `/`, `/api/status`, `/api/students`, `/api/echo`).
  - `SpringMvcSampleController.java`: демонстрационный прототип архитектуры в стиле Spring MVC с аннотационно-подобным разделением ответственности и REST-ответами.

### Инструкция по сборке и запуску

#### Вариант 1: Быстрый запуск (Windows)
Запустите командный файл:
```cmd
run.bat
```
После запуска сервер доступен в браузере по адресу: [http://localhost:8080](http://localhost:8080)

#### Вариант 2: Запуск вручную
```bash
# Компиляция:
javac -encoding UTF-8 *.java

# Запуск:
java -Dfile.encoding=UTF-8 -cp . Lab7_Main
```
